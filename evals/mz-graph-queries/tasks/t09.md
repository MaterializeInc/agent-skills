Create a view `{schema}.t09_effective_access(user_id text, doc_id text, level text)`. Groups form a hierarchy (`groups(id, parent_id)`); `permissions(group_id, doc_id, level)` grants a level on a document to a group; permissions flow from a group to all groups under it unless a group has its own explicit row for that document, which replaces the inherited one for that group and everything below it. Users belong to groups via `memberships(user_id, group_id)`. One row per (user, doc, level) the user effectively holds. This view backs an authorization check, so it must be a maintained view.
